# Per-Channel Docs Reorg + Square Source — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Split the docs into isolated per-channel sections (creating a self-contained Shopify-only `/shopify`), then add **Square** as a bookstore-system inventory source to the **main/platform docs only** — never reachable from the Shopify section.

**Architecture:** One Docusaurus site, multiple `@docusaurus/plugin-content-docs` instances (one per channel + Core + Canva + Sheets), each with its own folder, `routeBasePath`, and autogenerated sidebar. Global navbar/footer/tagline are kept channel-neutral so no Shopify visitor can see another channel. Square is added afterward, to Core/platform pages only.

**Tech Stack:** Docusaurus 3.7 (classic preset), React 19, Markdown/MDX, Yarn.

## Global Constraints

- `onBrokenLinks: 'throw'` — `yarn build` fails on any broken internal link. Every moved page requires its inbound links fixed.
- The `/shopify` section names **no other sales channel anywhere** (sidebar, navbar, footer, page body) and never uses **"point of sale"** or **"POS"**.
- **Square belongs ONLY in main/platform docs.** It must NOT appear in, or be reachable from, the `/shopify` section. (Single most important rule.)
- Existing source docs call these **"bookstore systems," never "POS."** Match that wording; avoid "POS"/"point of sale" in content site-wide. The third Shopify inventory source is worded **"an external in-store sales system."**
- Per user instruction: **do NOT commit, push, or deploy.** Each task ends by showing the diff for review. Commits happen only after explicit user approval.
- Match existing styling/components/nav patterns — **no redesign**.
- Planning artifacts live in repo-root `specs/` and `plans/`, **not** `docs/` (which is the published content folder).
- Verification command throughout: `yarn build` (compiles + link-checks). Dev preview: `yarn start`.

### Task 2: Build the Shopify section (6 pages, full content)

**Files:**
- Create: `shopify/overview.md` (replaces placeholder), `shopify/installing.md`, `shopify/inventory-source.md`, `shopify/importing-distributor-file.md`, `shopify/creating-books-manually.md`, `shopify/how-syncing-works.md`, `shopify/faq.md`

**Interfaces:**
- Produces: `/shopify/*` pages. Internal links stay within `/shopify` only.

Page outlines (Shopify-only language; no other channel; no "POS"):
1. `overview.md` (`sidebar_position: 1`) — "Overview — Bookhead for Shopify." Prominent near-top one-directional flow diagram: **external source → Bookhead (enrich: covers + bibliographic data) → your Shopify store.** Inventory enters via distributor file or manual entry; Bookhead enriches; writes to the merchant's own Shopify store; reads existing Shopify catalog **only** to keep inventory in sync (not a source).
2. `installing.md` (`2`) — install from the Shopify App Store, authorize against the merchant's own store, first-connect expectations.
3. `inventory-source.md` (`3`) — three sources in priority order: distributor file (recommended/primary → link to page 4), manual creation (→ page 5), an external in-store sales system. State plainly: Shopify is **not** the source of new inventory; read only for sync.
4. `importing-distributor-file.md` (`4`) — **most complete page.** Ingram "receiving a shipment" workflow end to end: obtain/export the distributor file, load into Bookhead, what Bookhead does (dedupe vs Shopify catalog, enrich, create/update), confirm results in Shopify.
5. `creating-books-manually.md` (`5`) — create a single product by hand (ISBN, quantity, price → enriched product); when to use vs distributor file.
6. `how-syncing-works.md` (`6`) — reads Shopify for sync/dedupe; writes new/updated products to the merchant's own Shopify store only; reiterate one-directional model + cadence.
7. `faq.md` (`7`) — "Frequently asked questions." Directly clears up the App Store reviewer's misunderstandings, phrased generically (no competitor names). Q&As include: **"Does this app list my products on other platforms?"** → No — Bookhead writes only to your own Shopify store; it does not list, post, or sync your products to any other platform or sales channel. **"Is Shopify the source of my inventory?"** → No — inventory comes from a distributor file or manual entry; Bookhead reads your Shopify catalog only to keep it in sync. **"What does the app write to my store?"** / **"What does it read?"** → reinforce the one-directional flow. Whatever specific points the reviewer flagged get a plain-language answer here.
